# 펠리카 (Perlica) — 전기 / 아츠 유닛 / 캐스터 ★5

**첫 캐스터 · 타이틀 히로인(아미야 포지션)**. 즉발 **전기 부착** + 쉬운 조건 **강제 감전 연계(아츠 취약)** + **깡딜 궁** + 불균형 추가딜. 연계 운용 부담 적고 조건 안 타 전기팟 외 아츠 조합에도 범용 공격 서포터. 1.2 장방이 출시 후 전기 전담 서폿. 주스탯 **지능**, 보조 **의지**. 리베리(엔드필드 공업 감독관).

### 🔑 강제 감전 = 부착 무관 아츠 취약
일반 감전은 전기 부착→다른 속성 부착으로 아츠 이상 발생이 필요하지만, 펠리카 연계 `forceShock`는 **부착 없이 직접 감전 + 아츠 취약 0.12** 부여 → 아무 아츠 딜러에게나 취약 셋업 가능(범용성의 근거). 향후 장방이(감전 소모/레벨업) 연동 대비. 첫 캐스터로 가드/캐스터/서포터 궁충 재능(질베르타) 수혜 직군에 포함.

### 역할
- 아츠 조합의 **범용 공격 서포터**(용병) · 전기팟 서브딜러. 스킬 우선순위: 궁 > 기본 > 연계 > 배틀(궁만 올려도 충분, 처형용이면 평타도).
- 연계가 메인 강공 발동 조건이라 **상시 발동** → 어느 아츠 파티에나 끼우기 좋음.

### 메커니즘 팁 (밸패 참고)
- **연계 = 강제 감전 → 아츠 받피증**: 감전은 「받는 아츠 피해↑」(받피증)라 **피증과 곱연산 → 효율 좋음**. **받피증량은 오리지늄 아츠 강도에 비례**.
- **강제 감전은 기존 아츠에 영향 없음**: 부착 무관 → 범용적으로 어디든 쓰기 좋음.
- **불균형 추피 30% 패시브**(오블리터레이션) → 궁·평타 처형 딜 잘 나옴. **처형은 펠리카로 쳐라**(단, 그러려면 펠리카 평타 마스터리 필요 — 안 그러면 400% 따리).
- **질베 궁 자연 부착 → 부식 전환**: 펠리카가 질베 궁 전에 배틀(전기 부착)을 써두면 질베 궁 자연 부착을 부식으로 챙길 수 있음(라라·이본팟에서 유용).

### 우리 구현 대조 (메커니즘만)

### 🐛 대조 중 반영한 갭
- **강제 감전 버킷 오류**: 펠리카/아크라이트 강제 감전이 취약(vuln)에 들어가 질베 아츠 취약과 **더해지고**, 아츠 강도 비례도 빠져 있었음 → 일반 감전(applyAttach)과 같은 **받피증(recv) + artsSub** 로 교정. 이제 질베 취약과 곱연산으로 겹치고 아츠 강도로 커진다. 완주율 100% 유지.
