# 질베르타 (Gilberta / 전작 안젤리나의 리컨비너) — 자연 / 아츠 유닛 / 서포터 ★6 (한정)

**서포터 1황**. **인게임 최고 광역 아츠 취약궁(방불 비례)** + **유일 배틀 몹몰이** + 강제 띄우기 연계(방불) + 가드/캐스터/서포터 궁충 효율 재능. 누킹형 딜러(이본·로시·레바테인) 코어 파츠. "빈자리 나면 일단 질베르타 넣으면 반은 간다". 주스탯 **의지**, 보조 **지능**. 불포(여우, 로도스).

- 인력 97→219% / 폭발 58→130% / 폭발 불균형 10

### 연계 스킬 「비전 지팡이 · 매트릭스 이동」 (쿨 20~19초)

### 궁극기 「비전 지팡이 · 중력장」 (게이지 90, 쿨 20초)

- 333→750% / 기초 아츠 취약 18→30% / 방불 1스택당 +1.75~3% / 감속 80% / 불균형 20

> 출시 초기 플레이어 실전 보고서. **장비·파티 추천은 초창기 자료라 제외** — 운용 메커니즘만 정리.

### 역할
- **자연 속성 서포터**. 핵심은 **궁극기의 아츠 취약**을 이용한 딜 증폭(딜 증가 체감 확실).
- **배틀** = 자연 부착 + **몹몰이**. 조합상 자연 부착이 필요하면 써 줌.
- **연계 = 띄우기** → 물리팟 전유물이던 **그로기(불균형)를 아츠팟에서도** 유발(체감 큼).
- 스킬 우선순위: **궁 > 연계 > 배틀 > 기본**. **궁극기만 마스터리 올려도 충분**.

### 메커니즘 팁 (밸패 참고)
- **배틀 몹몰이 vs 보스**: 잡몹은 경직돼 끌려오지만 보스는 발광해서 배틀 범위 밖으로 나가면 자연 부착이 안 됨 → 보스 패턴 보고 배틀 사용. *(실시간 위치 개념 — 우리 턴제 모델엔 해당 없음.)*
- **엔진**: 질베르타–펠리카는 스트라이커 파티가 아닌 이상 범용. 펠리카 강제 감전 → (아츠 이상) → 질베 연계 발동.
- **연계 방불 주의**: 질베 연계가 방어 불능을 부여해, 방불을 소모하는 다른 오퍼 조건(아델리아 연계 등)과 타이밍이 엉킬 수 있음.
- **역시너지**: 자연 부착이 이본의 냉기 부착과 만나면 동결/부식 반응 → 부착 누적형(라라)과는 처리 까다로움. 누킹형과 최적.
